💾 ¿Cómo actualizar el catálogo público?

  1. Haz clic en Exportar catálogo para publicar.
  2. En GitHub, abre el repositorio red-vivero-lima y reemplaza el archivo data.js por el descargado.
  3. Confirma el cambio con Commit changes. GitHub Pages publicará el nuevo catálogo.

Los cambios guardados aquí solo existen en este navegador hasta que exportes el archivo y lo publiques. No subas el panel local a GitHub.
